Scale & Beyond

Production-ready by design.

☁️ Cloud Run · Stateless Architecture

Each stadium gets its own orchestrator instance on Cloud Run. Config passed per request — no shared state. Auto-scales to zero between events, handles 10+ concurrent runs at match peaks.

🧩 Modular · Loosely Coupled Agents

Each agent is an independent LLM-powered unit with a well-defined input/output contract. Swap CrowdDensity for a different model? Zero changes to other agents. Real modularity — not just a buzzword.

⚡ Event-Driven Pipeline

Every agent cycle is triggered by an event — manual, scheduled, or alert-based. No polling loops. SSE pushes decisions downstream the moment they're ready. The entire system reacts, not polls.

📈 Multi-Stadium Scaling

Same codebase, different stadium config per request. IPL has 10 venues — each gets its own Cloud Run instance with zero code changes. Horizontal scale is free. The orchestrator is the reusable engine.

🔄 Resilience · Gemini Fallbacks

Shared gemini_client.py — detects daily quota exhaustion (returns None, no crash). Rate limits retry with 30s exponential backoff. Agents degrade gracefully. System never goes dark.
